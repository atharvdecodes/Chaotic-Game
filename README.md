 🎮 CHAOSVERSE – Survive the Unpredictable!

##  About the Game
CHAOSVERSE is an exciting 2D browser-based survival game where players must avoid unexpected obstacles and survive in a chaotic environment. The player must move, jump, and dodge dangerous obstacles while trying to stay alive for as long as possible.
The game features unpredictable challenges such as moving mutants, falling pianos, and confused controls. Players must use quick reflexes and smart movements to overcome these challenges.

## 🎯 Objective
The main objective is to survive for **2 minutes** without losing all three hearts. Avoid obstacles, react quickly, and stay alive until the timer reaches zero.

## 🕹️ Game Controls
| Key | Action |
|---|---|
| ← / A | Move Left |
| → / D | Move Right |
| Space / ↑ / W | Jump |
| S / ↓ | Sneak |

## ⚡ Game Features
- **Player Movement:** Move left and right across the game area.
- **Jumping:** Jump over obstacles to avoid collisions.
- **Sneaking:** Lower the character to avoid certain obstacles.
- **Three-Life System:** The player starts with three hearts.
- **Mutant Attack:** Mutants move across the game area and must be avoided.
- **Piano Rain:** Pianos fall from above and create unexpected danger.
- **Slippery Floor:** Player movement becomes difficult to control.
- **Confused Controls:** Movement directions get reversed temporarily.
- **Countdown Timer:** Survive for two minutes to complete the game.
- **Restart Option:** Restart the game after losing.

## 🛠️ Technologies Used
- HTML – Game structure
- CSS – Game design and styling
- JavaScript – Player movement, collision detection, obstacles, and game logic


## 🚀 How to Run the Game
1. Download or clone this repository.
2. Open the project folder.
3. Make sure all images are inside the `assets` folder.
4. Open `index.html` in a web browser.
5. Start playing and try to survive for two minutes!
